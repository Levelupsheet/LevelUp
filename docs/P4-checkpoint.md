# P4 boss and Golden checkpoint

Boss questions now require exactly three active, curated questions at tiers 4–5 in supported formats. The preview queries the full applicable bank. Encounter configuration and Golden randomness are generated on the server and preserved against client progress writes. Bosses use the actual progression curve, bounded scaling, independent player HP, and damage sufficient for an all-correct shielded victory. Starts are serialized with existing learning allocation and have a 15-minute cooldown, including abandoned encounters.

The canonical encounter is GameSession with trainingMode BOSS and server-owned encounter metadata. The obsolete completion endpoint referencing a nonexistent BossEncounter model now delegates to canonical session settlement. Settlement replays immutable graded answers and recorded consumable use: client HP, outcome, XP, count and encounter flags cannot fabricate rewards. Boss victory grants 100 bonus XP, a Silver chest (Gold for Golden), Shield/Restore (plus Fury for Golden), and 1 raffle entry (3 for Golden), subject to existing raffle limits. Defeat grants only earned question XP/tokens, not victory bonuses. All grants share the session's unique RewardClaim transaction.

Golden question entries are no longer granted at answer time. A correctly answered Golden question grants one entry only on surviving completion, with one successful question entry per user level. Failed/capped entry grants are not described as awarded. Normal tier-five enemies no longer misleadingly have Golden names.

31 tests pass, including hard-curated selection, genuine level scaling, all-correct shielded victory, and Golden-answer-then-defeat regression. TypeScript and full Next.js build pass. No production data was modified and no new schema was necessary. Runtime sweepstakes/history tables remain a deployment-hardening follow-up; existing valid session answers and inventory remain preserved. Settlement failures retain answers and offer a retry, rather than silently claiming rewards succeeded.
